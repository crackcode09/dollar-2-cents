# Dollar 2 Cents — Claude Code Reference

## What This Is

A personal project. Coin change calculator — converts a dollar amount into the minimum number of coins (quarters, dimes, nickels, pennies). Focus is on **exceptional visual design** and interactive rendering.

---

## Coding Rules

- No `console.log` left in production code
- No hardcoded magic numbers — use named constants for coin values
- Algorithm: greedy (largest coin first — quarter → dime → nickel → penny)
- Animate with CSS `@keyframes` + JS class toggling — no GSAP, no external animation libs
- Accessibility: input has label, results have aria-live region
- `prefers-reduced-motion` respected in CSS

---

## Brand / Aesthetic

- No PBC Linear branding whatsoever
- Dark background always (`#1C1917`)
- Coin colors: orange/amber family (`#EA580C`, `#F97316`, `#D97706`)
- Typography: oversized Fredoka headings, Nunito body
- Coins rendered as CSS circles — metallic feel via gradients and shadows
- One primary action per screen (Convert button)
